求职调研、学习计划、路线图这类**决策依据**放在这里，按抓取/制定日期分目录。
以后每次重做调研，新建一个 `YYYY-MM-DD/` 目录，不覆盖旧结论——市场在变，旧数据的价值在于对照。

```
research/
  2026-11-12/
    AI岗位调研-杭州上海.md        50 条 15-30K JD 的字段分析
    AI-Agent学习计划-30天.md      据此制定的 30 天执行计划
    学习路径图-original.html      archify 生成的路线图原稿（828KB，自带字体与运行时）
```

站点（`docs/`）会扫描本目录下所有 `.md`，渲染后放进「调研与计划」弹窗。新增文件不用改代码，重新构建即可。
